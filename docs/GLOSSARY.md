# Glossary

## Cognitive offloading

Moving part of a mental task to an external aid such as notes, software, search, a calculator, an AI system, or another tool.

In COAS, offloading is treated as task redistribution, not surrender of human judgment.

## Adaptive symbiosis

A changing division of labor between human and machine based on task load, stakes, reversibility, context, and explicit preference.

The goal is complementary capability rather than replacement.

## Cognitive load

The amount of mental effort a task demands. In the reference implementation it is a task parameter, not a clinical measurement.

## Stakes

The potential consequence of a wrong action or recommendation.

## Reversibility

How easily the result of an action can be undone.

## Human authority

The set of decisions that remain with the person: goals, consent, identity, meaning, values, override, and final judgment.

## Machine capability

A function a system can perform. Capability does not create authority.

## Adaptive boundary

The line between what is offloaded and what remains human-controlled. The boundary may move, but the human can always narrow it.

## Cognitive dependency

A condition in which assistance makes independent understanding or action harder over time. COAS treats avoidable dependency as a design failure.

## Provenance

Information about where a result, input, transformation, or decision came from so the human can inspect its origin.
