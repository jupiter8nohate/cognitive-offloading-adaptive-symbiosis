The LiveBrain layer gives every logical agent in both COAS swarms its own persistent operational state and independent action selection.

~~~text
100 HARMONI CORE AGENTS
+
100 PRIVACY AGENTS
=
200 AUTONOMOUS PLAYERS
~~~

The agents do not become human persons or conscious beings. In this architecture, autonomy means they independently select and execute authorized repository-local actions without requiring a human click for each choice.

~~~text
AGENT_AUTONOMY = INDEPENDENT_OPERATIONAL_CHOICE
AGENT_AUTONOMY != HUMAN_PERSONHOOD
~~~

## 𓁇 I⃟ N⃟ D⃟ E⃟ P⃟ E⃟ N⃟ D⃟ E⃟ N⃟ T⃟_C⃟ H⃟ O⃟ I⃟ C⃟ E⃟

Every agent receives its own energy level, pressure value, action scores, cryptographic decision seed input, signature, and result.

~~~text
AGENT_001 -> CHOOSE
AGENT_002 -> CHOOSE
AGENT_003 -> CHOOSE
...
AGENT_200 -> CHOOSE
~~~

The runtime seed is generated from `crypto/rand` when the CLI is not given an explicit seed. The seed is stored with the run so the resulting decision sequence can be reproduced later.

Cryptographic randomness does not create consciousness. It prevents every run from being a hard-coded static script while retaining auditability.

## 𐦂 R⃟ E⃟ P⃟ L⃟ I⃟ C⃟ A⃟ T⃟ I⃟ O⃟ N⃟ // B⃟ O⃟ U⃟ N⃟ D⃟ E⃟ D⃟

An agent may choose `FORK_EPHEMERAL_WORKER` when it has enough energy.

The helper exists only for that run and does not create a new repository, external account, remote process, or self-propagating network node.

Default limit:

~~~text
MAX_EPHEMERAL_WORKERS_PER_CYCLE = 32
HARD_MAX = 64
UNBOUNDED_REPLICATION = false
~~~
