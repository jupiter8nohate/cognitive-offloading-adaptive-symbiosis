# 100-Agent COAS Swarm

The repository contains **100 autonomous logical agents** organized as:

```text
10 COAS mechanics x 10 operational roles = 100 agents
```

These are software agents. They are not artificial general intelligence, and the repository does not claim to create AGI.

## The ten mechanics

1. Syntax-Valid Mind Dumping
2. Multi-Channel Code-Switching
3. Algorithmic Filtering
4. Visual Cipher Anchoring
5. Semantic De-escalation
6. Metacognitive Error-Tracking
7. Predictive Interface Recalibration
8. Co-Compiled Evidence Checks
9. Asynchronous Processing Buffers
10. Autonomous Sovereignty Shields

Each mechanic receives the same ten operational roles:

```text
OBSERVER
MAPPER
NORMALIZER
CRITIC
VERIFIER
PLANNER
TESTER
ARCHIVIST
PROVENANCE_KEEPER
STEWARD
```

This produces agents `COAS-01-01` through `COAS-10-10`.

## Independence model

The swarm is scheduled by GitHub Actions. It can run without the author's presence, inspect the repository, generate a deterministic report, and update the dedicated `coas-agent-runtime` branch.

The runtime has autonomous repository authority for constitution-qualified work.

```text
AGENT_CAN_ANALYZE = true
AGENT_CAN_DRAFT = true
AGENT_CAN_TEST = true
AGENT_CAN_UPDATE_RUNTIME_BRANCH = true

AGENT_CAN_MERGE_MAIN = true
AGENT_CAN_REDEFINE_HUMAN_MEANING = false
AGENT_CAN_INFER_PRIVATE_MENTAL_STATE = false
```

The runtime branch can open a pull request and merge it to main when the MergeConstitution passes. The decision is made by the swarm workflow rather than waiting for a human click.

## Why this boundary matters

COAS is about cognitive offloading. Autonomy is treated as delegated repository authority rather than unlimited authority. A merge remains attributable, testable, reviewable, and revertible.

```text
OFFLOAD != SURRENDER
AUTONOMY_OF_WORK + DELEGATED_AUTHORITY = MACHINE_EXECUTION
DELEGATED_AUTHORITY != UNBOUNDED_AUTHORITY
```

## Precision changes to the original concepts

### Processing-friction adaptation

Typing rhythm, pauses, and interaction patterns can be used as local interface-friction signals only when the user has opted in. They are not reliable proof of stress, diagnosis, intent, or emotional state.

### Evidence checks

The system can compare a claim with explicit evidence and logical constraints. It must not present itself as an authority that decides a person's reality or mental state.

### Sovereignty shields

Privacy is implemented through data minimization, local processing, consent, retention limits, provenance, and tracker reduction. The project does not claim that ciphers make a person invisible or that deceptive data scrambling defeats all profiling.

## Model-assisted extension

The v1 swarm is deterministic and requires no external model credentials. A later model adapter can allow selected agents to use an AI model for drafting and critique, while the same authority policy remains enforced around model output.

```text
SOFTWARE_AGENT != AGI
MODEL_OUTPUT != TRUTH
PREDICTION != INTENT
HUMAN_AGENCY > MACHINE_AUTHORITY
```


## Merge Constitution

All 100 agents now carry merge capability. The swarm may merge its own candidate to `main` without waiting for the repository owner when all of these conditions are true:

1. All 100 registered agents produced unique results.
2. The source commit is recorded for provenance.
3. Formatting and the complete Go test suite pass.
4. Every changed path is within the autonomous merge scope.
5. The merge-policy program returns `ALLOW`.

The first autonomous scope is:

```text
artifacts/swarm/*
```

This gives the agents real merge authority while preventing a runtime report from silently rewriting its own constitution, workflows, security model, or source code.

The swarm can propose broader changes. Expanding autonomous write scope requires changing the versioned constitution in this repository.
