# Linguistic Boundary Proof

COAS uses working software and code-poetry to demonstrate a narrower, testable claim:

```text
MACHINE_CAN_PARSE != MACHINE_CAN_OWN_MEANING
MACHINE_CAN_VALIDATE_SYNTAX != MACHINE_CAN_PROVE_INTENT
```

A compiler can determine whether a Go program is syntactically valid. Tests can determine whether specified behavior occurred. Neither operation proves the author's complete intended meaning, emotional context, cultural reference, or identity.

The repository intentionally places human-readable poetic invariants inside executable systems:

```text
PATTERN != PROOF
PROFILE != PERSON
MODEL != MIND
HUMAN_AGENCY > MACHINE_AUTHORITY
```

Those strings are machine-readable data and human-authored statements at the same time.

The engineering proof is not that machines can never interpret meaning. It is that syntactic validity and behavioral execution are different categories from authorship, consent, interpretation, and final human judgment.

That distinction is the core of Computational Metacognitive Bilingualism in this repository.
